# COO: Shoot 'em Up

Projeto da disciplina de Computação Orientada a Objetos, com o objetivo de reescrever um jogo do tipo *shoot 'em up* vertical, originalmente implementado em estilo procedural, aplicando boas práticas de orientação a objetos.

## Sobre o projeto

O jogo original (`Main.java` + `GameLib.java`) funciona, mas foi construído sem uma estrutura orientada a objetos adequada, com bastante código redundante e uso de vetores para gerenciar entidades como inimigos e projéteis.

O foco deste trabalho é reconstruir o código aplicando:

- Uma hierarquia de classes/interfaces bem definida para as entidades do jogo
- Encapsulamento adequado
- Herança e composição onde fizer sentido
- Uso do Java Collections Framework no lugar de arrays
